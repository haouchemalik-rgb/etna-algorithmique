# Groupe de schobe_c 1026222

Dans un premier temps je déclare un tableau pour stocker les caractères que je n'ai pas rencontré

Si c'est un nouveau char on le stock, à la fin on renvoi notre tableau stock

Le programme parcours toute la chaîne de caractère d'entrée s, la complexité algorithmique est donc linéaire, O(n) où n = len(s)
