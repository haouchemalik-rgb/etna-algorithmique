
Pour ce code, j'ai choisi d'utiliser une approche utilisant une boucle for pour générer les représentations binaires de tous les nombres compris entre 1 et n inclus. Chaque nombre est converti en sa représentation binaire en utilisant la fonction generate_binary. Les représentations binaires sont ensuite stockées dans une liste results qui est retournée à la fin de la fonction.

Ce qui donne une complexité linéaire par rapport à la valeur de l'entier n donné en entrée, soit O(n), où n est la valeur de n.
