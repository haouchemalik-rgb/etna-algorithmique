# Groupe de schobe_c 1026222

Pour ce code j'ai décider de faire un dictionnaire qui vas contenir tous mes caractère spéciaux ouvran et fermant.Je vais faire une boucle sur ma string en comparant
le caractère de ma string avec mon dictionnaire si il existe et que je vais le stocker.si mon premier charactère est un charactère fermant je regarde le dernier de ma liste si il est ouvrant sinon je return false.si ma liste n'est pas vide à la fin c'est aussi que c'est false.si tout est passer c'est que tout est bon.
 ce qui donne une complexité linéaire par rapport à la longueur de la chaîne d'entrée s, soit O(n), où n est la longueur de s.
